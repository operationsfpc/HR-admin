⚡ Quick Actions & Bulk Export

Generate multi-sheet Excel reports or copy all shareable links across colleges.

Add a college

Set the student access code (students type it to log into the student view). After adding, add its course link(s) below.

Colleges

For security the saved code isn't shown — you can only overwrite it.

Course links for a college

Add one or more HackerRank course links to a college. Each becomes a course you can sync (Dashboard) and tag (Topics).

Daily questions completed

Questions each student completed per day over the last 10 days, ending today. Days with no sync show a dot (no change recorded). Every student is listed, whether or not they rank on the leaderboard.

Assign topics to course questions

Pick a college, confirm its course link, then set a topic for each question. These power the “By topic” breakdowns. The course must be synced first (Dashboard tab).

Topic videos

Add a video link (e.g. YouTube) for each topic. Students see a “🎬 Watch” link under that topic. Save the question topics above first so all topics appear here.

Upload student roster

Excel/CSV needs Student Name and HackerRank Username (or profile URL). Optional columns: Register Number, Email, Department, Section, Year, Campus. Add the college in the Colleges tab first.

Add a single student

No file needed. Uses the College and Map to course chosen above. Name and HackerRank username are required.

Add multiple students (paste)

One student per line. Use Name, username — commas or tabs both work, so you can paste straight from a spreadsheet. A line with only a username is fine too (the username becomes the name). Optional extra columns, in order: Name, username, register no, email, department, section, year.

Attendance

Each college has its own attendance sheet. Paste a Google Sheets link for the selected college and its contents show below. The sheet must be shared “Anyone with the link → Viewer” (Share button in Google Sheets). Whatever columns and rows are in the sheet's first tab appear as-is.
